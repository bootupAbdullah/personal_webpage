I've been writing JavaScript for about two years now. It's fine. It gets the job done. But something always felt slightly off — like wearing shoes that almost fit.

Then I picked up Go.

## The thing about Go

Go is boring in the best possible way. There's one way to do most things, the tooling works out of the box, and the language doesn't try to be clever. When I read Go code I wrote six months ago, I understand it immediately. That's not always true with JavaScript.

## Concurrency that makes sense

Goroutines changed how I think about concurrent code. Spinning up a goroutine is as simple as:

```go
go doSomething()
```

That's it. No promise chains, no async/await juggling. Channels handle communication between goroutines cleanly, and the mental model is straightforward once it clicks.
